# InfoDropletsClient

This repository contains a Client-side desktop application for the **Info-Droplets project**.  
The software displays measurments from custom GPS tracker devices developed by the Hungarian SOPROBOTICS team.

![Image of the application frontend](https://i.imgur.com/a5VhaJO.png)

## About the Info-Droplets project

At the SOPROBOTICS group we are developing offline GPS tracker devices, called **Info-Droplets** to aid the research of the [Hungarian DAMBALL astronomer group](http://bajaitit.hu/magas-legkori-ballon-es-raketamodellezo-szakosztaly/).  
Our devices are used to model the **dark flight phase** of a falling meteorite.  
Further information about the project: https://meetingorganizer.copernicus.org/EPSC2022/EPSC2022-900.html
